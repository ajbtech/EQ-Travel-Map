# Asset attribution

This project bundles several images that are not original works of the
EQ Travel Map authors. They are included here under a fan-project
posture; EverQuest and related artwork remain the property of Daybreak
Game Company.

## Zone map

- **File:** `../zone_map.png`
- **Source:** Project 1999 Unofficial Zone Connection Map
- **Origin:** https://wiki.project1999.com/Zone_Connection_World
- **Credit:** *Originally created by Yurz Truly of the Project 1999
  server and later expanded by Matthew Gordon Roulston a.k.a Within
  Amnesia.*

The bundled `docs/sample_map.png` is a rendering this app produced from
the bundled sample log on top of the zone map above; the underlying
artwork carries the same credit.
